# ToInet-Mobile
**Версия для ПК:** [ToInet](https://github.com/AlexeyRF/ToInet)

**ToInet-Mobile** - приложение для Android, объединяющее в себе инструменты обхода блокировок: **Zapret (tpws)** со стратегиями Flowseal, **ByeDPI**, **Tor (ЛМ)**, **Opera Proxy**. 

## Основные возможности
*   **Easy-VPN**:
    *   Программа для использования минимизации вляния свинолётов на вашу интернет жизнь.
*   **Zapret (tpws) и ByeDPI**:
    *   Автономный движок `tpws` от bol-van, скомпилированный под Android.
    *   Встроенный тестер стратегий для подбора оптимальных параметров Zapret или ByeDpi.
*   **Режим системного VPN**:
    *   Раздельное туннелирование, можно маршрутизировать трафик отдельных приложений
*   **Tor (ЛМ)**:
    *   Встроенный луковый маршрутизатор.
*   **Socks-Reabilitator**:
    *   Прогон SOCKS5-прокси через byedpi, доступен так же режим без десинка.
*   **FakeVPN**:
    *   Прямое туннелирование с опциональной подменой SNI (FakeTLS).
*   **Opera Proxy**:
    *   Маршрутизация через прокси-серверы Opera.

## Порты по умолчанию

Если вам необходимо добавить в приложение прокси, то ToInet-Mobile используют фиксированные локальные порты:

| Инструмент             | Порт   | Тип прокси | 
|:-----------------------|:-------|:-----------|
| **Byedpi**             | `1080` | SOCKS5     |
| **Zapret (tpws)**      | `1081` | SOCKS5     | 
| **Easy-VPN (Xray)**    | `1791` | SOCKS5     |
| **Tor Socks5**         | `5242` | SOCKS5     |
| **Tor HTTP**           | `5267` | HTTP       |
| **Socks-Reabilitator** | `1788` | SOCKS5     |
| **Opera-Proxy**        | `1888` | SOCKS5     | 
| **FakeVPN**            | `1790` | SOCKS5     |

---

> [!WARNING]
> **Отваливается интернет при включении режима VPN.**
> В таком случае может потребоваться выключить частный DNS (Private DNS - DoT / DoH) в системных настройках сети Android, так как системный VPN перехватывает DNS-запросы через внутренний резолвер `pdnsd`.
