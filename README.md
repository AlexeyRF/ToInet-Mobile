# ToInet-Mobile - мобильный лаунчер для СОБ (ЛМ, TGWS, ByeDPI)

**Лицензия:** Все права принадлежат тем, кому они принадлежат.

## Порты
*   `5242` — Tor Socks5
*   `5267` — Tor HTTP
*   `1480` — TGWS Proxy

## Рекомендуемые настройки

### ByeDPI
Проверенный конфиг для **РТК** и **МТС**:
`-d1 -s1+s -s3+s -s6+s -s9+s -s12+s -s15+s -s20+s -s30+s -a1`

### TGWS (DC -> IP Mappings)
Рекомендуемые маппинги для **РТК**:
*   `2:149.154.167.220`
*   `4:149.154.167.220`

## Быстрое подключение к Telegram
*   [Подключить TGWS (1480)](https://t.me/socks?server=127.0.0.1&port=1480)
*   [Подключить Tor (5242)](https://t.me/socks?server=127.0.0.1&port=5242)
