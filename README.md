# ToInet-Mobile
**Версия для ПК:** [ToInet](https://github.com/AlexeyRF/ToInet)

**ToInet-Mobile** - приложение для Android, объединяющее в себе инструменты обхода блокировок: **Zapret (tpws)** со стратегиями Flowseal, **ByeDPI**, **Tor (ЛМ)**, **TGWS**, **Opera Proxy**. 

## Основные возможности
*   **Easy-VPN**:
    *   Программа для использования минимизации вляния свинолётов на вашу интернет жизнь.
    *   Поддержка протоколов и транспортов: **VLESS Reality**, **TLS**, **xhttp (splithttp)**, **WebSocket**, **gRPC**, **HTTPUpgrade**.
    *   Встроенный кэш проверенных рабочих серверов (мгновенный старт за миллисекунды без ожидания проверки сети).
    *   Фоновая подгрузка и автообновление подписок (включая зеркала на GitVerse и GitHub) с проверкой доступности узлов по TCP ping и балансировкой (`leastPing`).
*   **Zapret (tpws)**:
    *   Автономный движок `tpws` от bol-van, скомпилированный под Android.
    *   **22 готовые стратегии от Flowseal** (`zapret-discord-youtube`).
    *   **Встроенный тестер стратегий Zapret**: автоматическая проверка пресетов на реальных заблокированных сайтах (YouTube, Discord, Twitter/X, Rutracker и др.).
    *   Возможность ручного ввода любых аргументов `tpws`.
*   **ByeDPI**:
    *   Локальный SOCKS5-прокси с гибкими методами фрагментации TCP, десинхронизации TLS ClientHello и HTTP-модификаций.
    *   Встроенный тестер стратегий ByeDPI для подбора оптимальных параметров.
*   **Режим системного VPN**:
    *   Раздельное туннелирование, можно маршрутизировать трафик всего устройства или выбранных приложений
*   **Tor (ЛМ)**:
    *   Встроенный луковый маршрутизатор.
*   **TGWS**:
    *   Переписанный на Kotlin инструмент для получения быстрого доступа к Telegram посредствам WebSocket-прокси.
*   **Socks-Reabilitator**:
    *   Восстановления работоспособности SOCKS5-прокси через десинхронизацию, доступен так же режим без десинка.
*   **FakeVPN**:
    *   Прямое туннелирование с опциональной подменой SNI (FakeTLS).
*   **Opera Proxy**:
    *   Маршрутизация через прокси-серверы Opera.

## Порты по умолчанию

Если вам необходимо добавить в приложение прокси, то ToInet-Mobile используют фиксированные локальные порты:

| Инструмент             | Порт   | Тип прокси | 
|:-----------------------|:-------|:-----------|
| **Byedpi**             | `1080` | SOCKS5     |
| **Zapret (tpws)**      | `1081` | SOCKS5     | 
| **Easy-VPN (Xray)**    | `1791` | SOCKS5     |
| **Tor Socks5**         | `5242` | SOCKS5     |
| **Tor HTTP**           | `5267` | HTTP       |
| **TGWS Proxy**         | `1480` | SOCKS5     |
| **Socks-Reabilitator** | `1788` | SOCKS5     |
| **Opera-Proxy**        | `1888` | SOCKS5     | 
| **FakeVPN**            | `1790` | SOCKS5     |

---

> [!WARNING]
> **Отваливается интернет при включении режима VPN.**
> В таком случае может потребоваться выключить частный DNS (Private DNS - DoT / DoH) в системных настройках сети Android, так как системный VPN перехватывает DNS-запросы через внутренний резолвер `pdnsd`.
